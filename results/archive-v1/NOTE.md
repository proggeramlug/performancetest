# First round (superseded)

The first round used **scriptc 0.2.0** and **Porffor alpha-13**, which were outdated at the time. It had 9 implementations: no TS arena variants, no Swift and no Kotlin. scriptc 0.2.9 turned out to be about 9× faster than 0.2.0 on this workload, so these numbers should not be used. They are kept only for transparency.
